    사전 적합성 확인

    GO / HOLD / AI 불필요
  2. 01 / PAID

    AI/AX Discovery

    현재 업무와 병목을 분석하고 적용 판단, Scope, Risk, 필요 역할을 정의합니다.

    PROJECT BRIEF
  3. 02 / DESIGN

    Scope · Team

    산출물, 검증 기준, 책임 범위와 Evidence 기반 실행팀을 설계합니다.

    TEAM PLAN
  4. 03 / WORK

    계약 · Delivery

    계약과 보상을 명시하고 PM·QA를 포함한 유료 프로젝트로 실행합니다.

    DELIVERY
  5. 04 / PROVE

    검증 · Evidence

    결과, 한계, Capability Gap과 다음 실행 단계를 기록합니다.

    VERIFIED RESULT

REVENUE-FIRST ROADMAP / EXIT CRITERIA, NOT CALENDAR

기간이 아니라
실제 수요와 반복으로 다음 단계를 엽니다.

  1. STAGE 0 / CURRENT

    WWW + Intake

    Offer와 두 접수 기준을 확정하고 실제 Lead를 받습니다.

    Exit: 접수 → Operator 확인 → Next Step
  2. STAGE 1 / NEXT

    수동 수익 운영

    Discovery, Talent Search, Shortlist, Proposal을 직접 수행합니다.

    Exit: Brief 3건 + 유료 계약 또는 실패 근거
  3. STAGE 2

    Work Platform

    실제 Talent·Project와 Match Assessment를 제품화합니다.

    Trigger: 반복 가능한 시장 데이터
  4. STAGE 3

    Ops System

    누락과 협업 비용이 발생한 운영 Workflow를 시스템화합니다.

    Trigger: Lead 5+ 또는 Operator 2+
  5. STAGE 4

    HBKR Cafe

    실제 Meetup과 Vertical Community의 사람·활동을 연결합니다.

    Trigger: 정기 활동 + 운영 책임자
  6. STAGE 5

    Lab · Learn

    반복 실험과 학습 활동을 Evidence 생산 체계로 분리합니다.

    Trigger: Experiment 3+ / Session 2+
  7. STAGE 6

    API · ID · Status

    중복 데이터, 통합 로그인, 유료 운영 필요가 입증되면 만듭니다.

    Trigger: Shared System 비용이 분리 비용보다 큼
